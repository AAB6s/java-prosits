## Installation

Install Java JDK 17 using Winget:

```bash
winget install Microsoft.OpenJDK.17
```

Verify installation:

```bash
java -version
javac -version
```

## Setup

- Java JDK installed
- Commands executed from the project directory

## Files

- `ZooManagement.java`
- `Hello3IA1.java`

## Run

### Hello3IA1

```bash
javac Hello3IA1.java
java Hello3IA1
```

java Hello3IA1.java
