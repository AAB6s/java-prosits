## Installation

Install Java JDK 17 using Winget:

```bash
winget install Microsoft.OpenJDK.17
```

Verify installation:

```bash
java -version
javac -version
```

## Setup

- Java JDK installed
- Commands executed from the project directory

## Files

- `Animal.java`
- `Zoo.java`
- `Main.java`

## Run

### ZooManagement

```bash
cd src
javac *.java
java Main
```
